# Найважливіші атрибути та методи бібліотеки Colorama

Бібліотека **Colorama** призначена для роботи з кольоровим текстом у консолі Python. Вона дає змогу змінювати колір тексту, колір фону та стиль його відображення.

## 1. Основні атрибути

| Атрибут | Призначення |
|---|---|
| `colorama.Fore` | Містить атрибути для зміни кольору тексту: `RED`, `GREEN`, `BLUE`, `YELLOW`, `WHITE` тощо. |
| `colorama.Back` | Містить атрибути для зміни кольору фону тексту. Наприклад, `RED`, `GREEN`, `BLUE`. |
| `colorama.Style` | Відповідає за стиль тексту: `BRIGHT` — яскравий, `DIM` — тьмяний, `NORMAL` — звичайний, `RESET_ALL` — скидання всіх налаштувань. |
| `colorama.AnsiToWin32` | Клас, який перетворює ANSI-команди керування кольорами у відповідний формат для Windows. |

## 2. Найважливіші методи та функції

| Метод / функція | Призначення |
|---|---|
| `colorama.init()` | Ініціалізує бібліотеку та налаштовує підтримку кольорового тексту в консолі. |
| `colorama.just_fix_windows_console()` | Налаштовує підтримку ANSI-кольорів у консолі Windows. |
| `colorama.deinit()` | Вимикає перехоплення та обробку кольорових команд, налаштовані через `init()`. |
| `colorama.reinit()` | Повторно вмикає обробку кольорових команд після виклику `deinit()`. |

## 3. Приклад використання

```python
import colorama
from colorama import Fore, Back, Style

colorama.init(autoreset=True)

print(Fore.RED + "Червоний текст")
print(Fore.GREEN + "Зелений текст")
print(Back.BLUE + "Текст на синьому фоні")
print(Style.BRIGHT + "Яскравий текст")
print(Style.DIM + "Тьмяний текст")
